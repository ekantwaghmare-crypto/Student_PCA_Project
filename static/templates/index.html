Student PCA Analyzer

A web-based machine learning module for preprocessing student performance data, applying Principal Component Analysis, retaining approximately 95% cumulative variance, and visualizing important patterns.

Start Analysis

About Principal Component Analysis

PCA is a dimensionality reduction technique used to transform high-dimensional data into a smaller set of principal components.

Dimensionality Reduction

PCA reduces the number of dimensions while preserving the important variation present in the dataset.

Variance Preservation

The system automatically selects the minimum number of principal components required to retain at least 95% cumulative variance.

Pattern Visualization

PC1 and PC2 are used to visualize student records in a two-dimensional PCA space.

Feature Interpretation

PCA loadings help identify the contribution of processed features to the principal components.

Data Preprocessing

{{ preprocessing_status }}


  • Duplicate records are removed.
  • Missing numerical values are replaced using the column mean.
  • Missing categorical values are replaced using the column mode.
  • Categorical features are converted into numerical form using One-Hot Encoding.
  • Numerical features are standardized using StandardScaler.
  • PCA is applied to the complete processed feature matrix.
  • Components are automatically selected to retain at least 95% cumulative variance.
