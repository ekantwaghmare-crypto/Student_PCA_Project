🧠 What is PCA?

Principal Component Analysis (PCA) is a dimensionality reduction technique used to simplify datasets containing many features. It transforms the original features into new variables called Principal Components while preserving important information.

In this project, PCA is applied to student performance data to reduce complexity, identify important patterns, and visualize student data in a simpler form.

1️⃣ Standardize Bring features to a common scale.
2️⃣ Transform Convert original features into principal components.
3️⃣ Reduce Keep important information using fewer components.
4️⃣ Visualize Understand patterns using PCA graphs.
